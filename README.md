**1. 이 연구는 무엇을 알아보려던 연구인가?**

연구 주제는 **‘식생활에 따른 비만 여부 분석’**이야.

구체적으로는 다음 질문을 확인하려고 했어.

* 아침 식사, 외식, 과일·채소 섭취, 음주 등의 특성이 비만 여부와 관련되어 있는가?
* 남성과 여성에서 각각 어떤 관련 요인이 나타나는가?
* 단순 비교에서 나타난 관련성이 연령·소득 등을 고려한 후에도 유지되는가?

한 문장으로 설명하면 다음과 같아.

> **국민건강영양조사 자료를 활용해 성인 남녀의 식생활 특성과 비만의 관련성을 분석하고, 인구사회학적 요인을 함께 고려해 결과를 살펴본 연구야.**

여기서 중요한 건 **조사 시점의 식생활과 비만 상태를 분석한 단면연구**라는 점이야. 미래의 비만 발생을 추적한 연구는 아니므로, “어떤 식습관이 비만의 원인이라는 것을 증명했다”고 설명하면 안 돼.

**3. 비만은 어떻게 정의했나?**

BMI와 허리둘레를 **동시에** 사용했어.

| 성별 | 연구에서 비만으로 분류한 조건            |
| -- | --------------------------- |
| 남성 | **BMI ≥ 25이면서 허리둘레 ≥ 90cm** |
| 여성 | **BMI ≥ 25이면서 허리둘레 ≥ 85cm** |

현재 코딩은 다음과 같아.

```r
조건을 모두 충족하면 → 비만 = 1
그 외에는          → 비비만 = 0
```

예를 들어 남성이 BMI 27이지만 허리둘레가 88cm라면, 이 연구에서는 `0`으로 분류돼.

따라서 **비비만=0인 사람을 모두 ‘정상 체중’이라고 부르면 안 돼.** 정확히는 “이번 연구의 두 비만 조건을 동시에 충족하지 않은 집단”이야.

원래 코드는 반대로 비만=0이었는데, 이번에 비만=1로 바꿨어. 그 결과 **오즈비 방향만 뒤집혔고 p값과 AUC는 같았어.**

**4. 어떤 설명변수를 사용했나?**

크게 **인구사회학적 특성**과 **식생활 특성**으로 나눌 수 있어.

| 구분        | 주요 변수                       |
| --------- | --------------------------- |
| 인구사회학적 특성 | 연령, 소득, 교육 수준, 혼인상태 재분류     |

| 외식        | 외식 빈도                       |
| 식품 섭취     | 채소·과일 섭취 빈도                 |
| 기타 식생활    | 식이보충제 복용 경험, 영양표시 인지        |

모든 변수를 그대로 사용한 것은 아니고, 일부를 몇 개 그룹으로 묶었어. 이것을 **재범주화**라고 해.

예를 들어 연령은 교차분석에서 19~29세·30대·40대 등으로 묶었지만, 회귀분석에서는 **실제 나이**를 사용했어.

외식 빈도는 현재 코드에서 이렇게 묶여 있어.

| 재분류 코드     | 정확한 의미   |
| ---------- | -------- |
| `out_gr=1` | 하루 1회 이상 |
| `out_gr=2` | 주 1~6회   |
| `out_gr=3` | 월 3회 이하  |

이 문항의 외식에는 **배달·포장·급식 등도 포함**돼. 식당에 직접 가서 먹는 것만 의미하지 않아.

과일과 채소는 **응답번호가 커질수록 덜 자주 먹는 방향**이야.

| 원래 코드 | 섭취 빈도    |
| ----: | -------- |
|     1 | 하루 3회 이상 |
|     2 | 하루 2회    |
|     3 | 하루 1회    |
|     4 | 주 5~6회   |
|     5 | 주 2~4회   |
|     6 | 주 1회     |
|     7 | 월 2~3회   |
|     8 | 월 1회     |
|     9 | 월 1회 미만  |

특히 **과일 교차분석에는 재분류한 변수 `fr_gr`를 사용하고, 회귀분석에는 원래 9단계 변수 `LS_FRUIT`를 사용했다는 차이**가 있어.

**5. 왜 남녀를 따로 분석했나?**

논문에서는 **성별과 비만 여부의 교차검정에서 유의한 차이가 나타나 성별을 나누었다**고 설명했어. 이번 재현에서도 성별과 비만 여부의 관련성은 유의했어.

분석 목적은 남성과 여성 각각에서 식생활과 비만의 관련성을 살펴보는 것이었어.

다만 면접에서는 이렇게 구분해서 설명하는 게 정확해.

> “성별에 따른 비만 분포의 차이를 확인하고, 남녀 각각의 관련 요인을 살펴보기 위해 성별로 나누어 분석했습니다.”

**여성에서 유의하고 남성에서 유의하지 않았다는 것만으로 ‘두 성별의 효과가 통계적으로 다르다’고 증명한 것은 아니야.** 그 차이를 직접 검정하려면 별도 상호작용 분석 등이 필요해.

**6. 복합표본 분석은 왜 사용했나?**

국민건강영양조사는 단순 무작위 표본이 아니라 **층화·집락 등의 표본설계를 사용한 조사**야.

그래서 코드에서 다음 정보를 지정했어.

```r
svydesign(
  ids = ~psu,
  strata = ~kstrata,
  weights = ~wt_itvex,
  data = ...
)
```

| 항목         | 의미              |
| ---------- | --------------- |
| `psu`      | 조사 집락, 1차 추출단위  |
| `kstrata`  | 층화변수            |
| `wt_itvex` | 코드에서 사용한 조사 가중치 |

쉽게 말하면, **조사에 참여한 사람들의 수만 세는 것이 아니라 표본이 뽑힌 구조를 고려해서 분석한 것**이야.

여기서 가중치는 비만과 비비만의 인원을 맞추는 머신러닝의 `class_weight`와 달라. 남녀에게 임의로 다른 가중치를 준 것도 아니고, **제공된 가중치 변수를 사용했어.**

단, 영양·검진 변수를 함께 사용하는 이번 분석에 `wt_itvex`가 적절한지는 이용지침으로 추가 확인해야 해. 이번 재실행에서는 원본 코드의 선택을 유지했어.

**9. 교차검정에서는 무엇이 유의했나?**

`p<0.05` 기준으로 정리하면 다음과 같아.

| 성별 | 유의한 관련성을 보인 변수                                                   |
| -- | ---------------------------------------------------------------- |
| 남성 | 연령군, 혼인상태 재분류, 저녁 동반 식사, 음주량                                     |

또 유의하지 않은 결과는 “관련성이 전혀 없다”는 증명이 아니라, **이 분석에서는 유의한 근거를 얻지 못했다**는 뜻이야.

**10. 로지스틱 회귀 결과는 어떻게 읽나?**

결과가 비만/비비만의 두 가지라서 로지스틱 회귀를 사용했어.

지금은 비만=1이므로 다음처럼 읽으면 돼.

| OR     | 해석        |
| ------ | --------- |
| 1보다 큼  | 비만 오즈가 높음 |
| 1보다 작음 | 비만 오즈가 낮음 |
| 1      | 오즈 차이가 없음 |

**오즈는 확률과 달라.** 따라서 OR 1.2를 “비만 확률이 20% 높다”고 표현하지 않고, “비만 오즈가 20% 높다”고 표현해야 해.

여성 주모델의 주요 결과는 다음과 같아.

| 변수           |     비만 OR |     p값 | 현재 모델 기준 해석                            |
| ------------ | --------: | -----: | -------------------------------------- |
| 연령           | **1.022** | <0.001 | 1세 증가당 비만 오즈 약 2.2% 증가                 |
| 소득 수준        | **0.858** |  0.040 | 코드 한 단계 증가당 약 14.2% 감소                 |
| 교육 수준        | **0.809** |  0.007 | 코드 한 단계 증가당 약 19.1% 감소                 |
| 과일 섭취 빈도     | **1.109** |  0.012 | 덜 자주 먹는 응답범주로 한 단계 이동할 때 약 10.9% 증가    |
| 채소 섭취 빈도 재분류 | **0.618** |  0.022 | 덜 자주 먹는 재분류 그룹으로 한 단계 이동할 때 약 38.2% 감소 |
| 혼인상태 재분류     | **0.732** |  0.045 | 실제 집단 명칭 확인 후 해석 필요                    |

여기서 과일·채소 등의 범주 간 간격이 다른데도 숫자로 넣었기 때문에, **단계마다 같은 변화가 있다는 가정 아래 나온 결과**야.

특히 채소 결과는 예상과 반대처럼 보이지만, 이를 곧바로 예방 효과로 해석하면 안 돼. 해당 질문에는 김치·장아찌와 국·찌개 속 채소도 포함되고, 정확한 섭취량을 측정한 것도 아니야. **범주형 처리, 다른 관련 요인, 역인과 가능성 등을 검토해야 하는 결과**야.

남성에서는 음주 관련 계수를 제외하면 다음 변수가 유의했어.

| 변수           | 비만 OR |    p값 |
| ------------ | ----: | ----: |
| 외식 빈도 재분류 코드 | 0.822 | 0.033 |
| 소득 수준 코드     | 0.869 | 0.039 |
| 혼인상태 재분류 코드  | 0.680 | 0.017 |

혼인상태는 코드의 실제 묶음과 논문의 ‘동거 배우자 유무’라는 설명이 일치하는지 아직 확인이 필요해.

**11. 교차검정과 회귀분석 결과가 달랐던 예시는?**

| 다변량 회귀분석 | **0.705** |

단순 비교에서는 관련성이 보였지만, 주회귀에서는 유의하지 않았어.

다만 두 분석은 **다른 변수의 보정 여부뿐 아니라 검정 방식도 달라.** 교차검정은 범주 전체의 차이를 보고, 현재 회귀는 아침 식사 응답번호를 숫자로 넣어 일정한 추세를 추정했어. 따라서 변화가 전부 다른 변수의 보정 때문이라고 단정할 수는 없어.

---

**12. 여성에서 추가로 실시한 ‘보정 전후 비교’는 무엇인가?**

원본 코드 후반부에서는 **외식·음주 변수 각각에 대해 연령·소득을 보정하기 전후를 비교**했어.

여기서 외식 변수는 `factor(out_gr)`로 넣어서, **하루 1회 이상 외식하는 집단을 기준으로 다른 집단을 비교**했어.

| 외식 빈도   | 보정 전 비만 OR |     p값 | 연령·소득 보정 후 OR |    p값 |
| ------- | ---------: | -----: | ------------: | ----: |
| 주 1~6회  |      1.606 |  0.047 |         1.312 | 0.265 |
| 월 3회 이하 |      2.740 | <0.001 |         1.360 | 0.242 |

**보정 전에는 차이가 있었지만, 연령·소득을 고려한 뒤에는 두 비교 모두 유의하지 않았어.**

이 결과를 통해 설명할 수 있는 것은 다음이야.

> **외식 빈도와 비만의 단순 관련성을 해석할 때 연령과 소득 같은 인구사회학적 특성을 함께 고려할 필요가 있었다.**

참고로 이 추가 모델은 **외식+연령+소득만 사용한 모델**이고, 앞의 주모델은 더 많은 변수를 함께 넣었어. 외식의 숫자형·범주형 처리도 달라서 OR가 서로 다른 것은 모순이 아니야.

음주 빈도 역시 일부 그룹에서 보정 전 유의했던 차이가 보정 후에는 유의하지 않았어. 음주량의 별도 보정모델에서는 일부 그룹이 유의했지만, 정확한 잔 수 명칭은 코드북 대조가 남아 있어.

**13. VIF 검사에서 발견된 문제는 무엇인가?**

VIF는 설명변수 사이의 정보 중복, 즉 다중공선성을 확인하는 데 사용하는 지표야.

이번에는 **음주 빈도와 음주량을 동시에 넣으면서 완전 공선성**이 발생했어.

두 변수에서 비음주자로 묶인 **1,285명이 정확히 같았고**, 두 변수를 더미변수로 만들면서 일부 변수가 다른 변수들의 조합과 완전히 같아졌어.

그 결과는 다음과 같아.

* 두 성별 모델에서 음주량 계수 하나가 추정되지 않음.
* `vif()`에서 오류가 발생함.
* 이번에는 오류를 기록하고 후속 계산을 이어갔음.

따라서 **“다중공선성을 검사해서 문제가 없음을 확인했다”는 설명은 현재 코드 기준으로 맞지 않아.** 음주 변수의 구성은 수정 후 다시 분석해야 해.

**14. ROC와 AUC는 무엇을 보여줬나?**

AUC는 모델이 비만과 비비만을 **얼마나 잘 구분하는지** 보는 지표야.

| 구분 |   당시 논문 | 이번 코드 재실행 |
| -- | ------: | --------: |
| 남성 |   0.569 | **0.581** |
| 여성 | 약 0.710 | **0.692** |

여성 모델이 수치상 더 높았어. 다만 **AUC 0.692를 ‘정확도 69.2%’라고 표현하면 안 돼.**

또 현재 코드에서는 복합표본 회귀와 별도로 **일반 로지스틱 회귀를 적합한 뒤, 같은 학습자료에서 AUC를 계산**했어.

따라서 다음과 구분해야 해.

* 새로운 데이터에서 검증한 성능이 아님.
* 외부검증을 수행한 결과가 아님.
* 복합표본 주모델의 가중 AUC가 아님.

당시 논문과 첨부 재검토 코드의 변수 처리 방식에도 차이가 있어서 수치가 그대로 재현되지는 않았어.

* 식생활 요인의 단순 관련성과 여러 변수를 함께 고려한 관련성을 구분했다.
