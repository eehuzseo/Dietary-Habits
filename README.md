**1. 이 연구는 무엇을 알아보려던 연구인가?**

연구 주제: **‘식생활에 따른 비만 여부 분석’**


* 아침 식사, 외식, 과일·채소 섭취, 음주 등의 특성이 비만 여부와 관련되어 있는가?
* 남성과 여성에서 각각 어떤 관련 요인이 나타나는가?
* 단순 비교에서 나타난 관련성이 연령·소득 등을 고려한 후에도 유지되는가?


> **국민건강영양조사 자료를 활용해 성인 남녀의 식생활 특성과 비만의 관련성을 분석하고, 인구사회학적 요인을 함께 고려해 결과를 살펴본 연구야.**

중요:  **조사 시점의 식생활과 비만 상태를 분석한 단면연구**

**6. 복합표본 분석은 왜 사용했나?**

국민건강영양조사는 단순 무작위 표본이 아니라 **층화·집락 등의 표본설계를 사용한 조사**


```r
svydesign(
  ids = ~psu,
  strata = ~kstrata,
  weights = ~wt_itvex,
  data = ...
)
```

| 항목         | 의미              |
| ---------- | --------------- |
| `psu`      | 조사 집락, 1차 추출단위  |
| `kstrata`  | 층화변수            |
| `wt_itvex` | 코드에서 사용한 조사 가중치 |

 **조사에 참여한 사람들의 수만 세는 것이 아니라 표본이 뽑힌 구조를 고려해서 분석한 것**

여기서 가중치는 비만과 비비만의 인원을 맞추는 머신러닝의 `class_weight`와 다름.  **제공된 가중치 변수를 사용.**

**12. 여성에서 추가로 실시한 ‘보정 전후 비교’는 무엇인가?**

원본 코드 후반부에서는 **외식·음주 변수 각각에 대해 연령·소득을 보정하기 전후를 비교**

여기서 외식 변수는 `factor(out_gr)`로 넣어서, **하루 1회 이상 외식하는 집단을 기준으로 다른 집단을 비교**

| 외식 빈도   | 보정 전 비만 OR |     p값 | 연령·소득 보정 후 OR |    p값 |
| ------- | ---------: | -----: | ------------: | ----: |
| 주 1~6회  |      1.606 |  0.047 |         1.312 | 0.265 |
| 월 3회 이하 |      2.740 | <0.001 |         1.360 | 0.242 |

**보정 전에는 차이가 있었지만, 연령·소득을 고려한 뒤에는 두 비교 모두 유의하지 않음.**


> **외식 빈도와 비만의 단순 관련성을 해석할 때 연령과 소득 같은 인구사회학적 특성을 함께 고려할 필요가 있었다.**
